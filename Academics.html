Units on offer
Units on offer: choose the term, then add units one by one, or every programme unit of a course for a year and semester at once (a course's units are set up in Settings > Program Setup > Programme Units). Students can only be registered for units on offer in a term. The bin removes an offer nobody is registered for.

Student units upload
Student units upload: register many students at once from a CSV file (in Excel: File > Save As > CSV). It needs the columns AdmNo and UnitCode; a Term column is optional, otherwise the term chosen here is used. Check file shows every line first; Register then registers the lines marked OK. The file itself is not kept.

Student unit registration: find the student, choose the term, then tick the units they take and Save registration. Only units on offer in that term for the student's course (or for any course) are listed.

Lecturer units
Lecturer units: choose the term, then pick the lecturer who teaches each unit on offer. It is saved as soon as you pick. "Show" narrows the list to one lecturer's units.

Units register
Units register: enter the unit code, title and credit hours, then Save unit. The pencil loads a unit for a change and the bin removes one that is not used by a course, an offer or a registration. Find narrows the list by code or title.
